# Rasp Hide — тексты для форм магазинов расширений

Готовые тексты для Chrome Web Store, Firefox Add-ons, Edge Add-ons и Opera Add-ons.
Тексты **одни на все магазины**: правка описания делается здесь и переносится во все
формы, иначе витрины разойдутся. Название и краткое описание берутся из манифеста
(`name`, `description`) и здесь только повторены — менять их нужно в `manifest.json`.
Чек-лист сабмита — [STORE_CHECKLIST.md](STORE_CHECKLIST.md).

Разделы «Общие тексты» и «Картинки» — для всех магазинов; дальше — поля, которые есть
только в конкретной форме.

## Общие тексты

**Название** (`name`, ≤ 75): Rasp Hide

**Краткое описание** (`description`, ≤ 132):
Скрытие ненужных пар в расписании ТПУ на ro-rasp.tpu.ru: по предмету, преподавателю и виду занятия.

**Подробное описание** (одно и то же во всех магазинах):

```
Rasp Hide убирает из расписания ТПУ (ro-rasp.tpu.ru) пары, на которые вы не ходите: например, факультативные дисциплины, которые вы не выбирали.

Как пользоваться
• Наведите курсор на пару и нажмите «Скрыть».
• Выберите, что скрывать: только этот вид занятия (например, только лекции)
  или все занятия по предмету.
• Скройте пару у конкретного преподавателя или у всех.
• На месте скрытой пары остаётся бледная пометка «скрыто» — наведите на неё
  и нажмите «Вернуть».

Возможности
• Правила по предмету, преподавателю и виду занятия (лекции, практики, лабораторные).
• У пары с несколькими преподавателями можно скрыть одного из них.
• Два вида скрытия: пометка «скрыто» или зачёркивание.
• Окно по клику на иконку: тумблер, число скрытых пар на странице, список правил
  с поиском, добавление правила вручную. Выключить скрытие — Alt+Shift+H.
• Работает на всех страницах расписания: группы, преподаватели, аудитории, архив.
• Правила синхронизируются между вашими устройствами средствами браузера;
  есть экспорт и импорт в файл.
• Светлая и тёмная тема — по настройке системы.

Приватность
Расширение ничего не собирает и никуда не отправляет: у него нет сервера,
аналитики и сетевых запросов. Работает только на ro-rasp.tpu.ru.

Исходный код (MIT): https://github.com/feni0707/rasp-hide
```

**Категория:** Chrome Web Store — Education (запасной вариант — Productivity → Tools);
в остальных магазинах — «Образование», если такая категория есть, иначе Productivity
(в AMO — Other).

**Язык:** русский.

**Лицензия:** MIT. **Исходный код:** `https://github.com/feni0707/rasp-hide`.

**Заметка для проверяющего** (AMO — Notes to Reviewer, Edge — Notes for certification,
Opera — комментарий к сабмиту):

```
Расширение работает только на https://ro-rasp.tpu.ru/ — это открытое расписание
Томского политехнического университета, вход и учётная запись не нужны.
Проверка: открыть расписание любой группы, навести курсор на пару, нажать «Скрыть».
Код в пакете — исходный, без сборки и минификации; сетевых запросов нет.
Source: https://github.com/feni0707/rasp-hide
```

## Chrome Web Store: вкладка Privacy practices

Эти же формулировки годятся для похожих полей других магазинов (назначение, права,
доступ к сайту).

**Single purpose:**

```
Скрывать выбранные пользователем пары в расписании ТПУ на сайте ro-rasp.tpu.ru.
```

**Обоснование права `storage`:**

```
Хранение правил скрытия (предмет, преподаватель, вид занятия), тумблера и вида скрытой
пары в chrome.storage.sync, а также подсказок для ручного ввода правила
(названия предметов и ФИО с открытых страниц расписания) в chrome.storage.local.
```

**Обоснование доступа к сайту** (`content_scripts.matches: https://ro-rasp.tpu.ru/*`):

```
Скрипт работает только на страницах расписания ТПУ: читает таблицу расписания
и скрывает пары, подходящие под правила пользователя. На другие сайты доступа нет,
сетевых запросов расширение не делает.
```

**Remote code:** «No, I am not using remote code» — весь код в пакете, `eval` и внешних
скриптов нет (проверяет `tests/manifest.test.js`).

**Data usage:** ни одна категория не отмечается — данные не покидают устройство
(кроме штатной синхронизации браузера) и не передаются разработчику или третьим лицам.
Отметить все три сертификата (не продаю данные, не использую не по назначению,
не использую для кредитоспособности).

**Privacy policy URL:** `https://github.com/feni0707/rasp-hide/blob/main/PRIVACY.md`
(станет доступен после публикации репозитория и слияния в `main`).

## Firefox Add-ons (AMO)

- **Summary** — краткое описание из манифеста; **Description** — подробное описание выше.
- **Платформа** — только настольный Firefox.
- **Privacy Policy** — поле текстовое: вставить содержимое `PRIVACY.md`.
- **Сбор данных** — в форме не заполняется: берётся из манифеста
  (`data_collection_permissions: none`).
- **Исходный код** — «не требуется»: в пакете нет минифицированного или собранного кода.
